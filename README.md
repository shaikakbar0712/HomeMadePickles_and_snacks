# 🥒 HomeMade Pickles & Snacks

A cloud-based web application that allows users to explore and order authentic homemade pickles and snacks. The platform offers a simple, responsive interface where customers can browse products, manage their cart, and place orders online.

## 🌐 Live Demo

🚀 Live Website:
https://homemadepickles-and-snacks.onrender.com/

🍗 Non-Veg Pickles:
https://homemadepickles-and-snacks.onrender.com/non_veg_pickles

# ⚙ Installation

## 1 Clone Repository

```bash
git clone https://github.com/shaikakbar0712/HomeMadePickles_and_snacks.git
```

## 2 Move into Project

```bash
cd HomeMadePickles_and_snacks
```

## 3 Create Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

## 4 Install Dependencies

```bash
pip install -r requirements.txt
```

## 5 Run Application

```bash
python app.py
```

Open browser

```
http://127.0.0.1:5000
```
